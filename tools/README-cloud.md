# 租卡工具 changji-cloud

四家云的 GPU 机器：比价、开机、关机、释放，以及**把模型第一时间弄进新机器**。

解开就能跑，不用先装 Python 和 PySide6。

```
macOS / Linux   ./changji-cloud
Windows         changji-cloud.exe
```

Windows 那个包会带一个控制台窗口——留着它，启动出问题时原因就打在上面。

## 先填钥匙

顶上一排选平台，右边填钥匙，点保存。存在 `~/.config/changji/cloud.json`
（权限 600），也认环境变量。

| 平台 | 去哪儿拿 | 环境变量 |
|---|---|---|
| AutoDL | 控制台 → 账号 → 设置 → 开发者Token（要先实名） | `AUTODL_TOKEN` |
| PPIO | 设置 → API 密钥管理 | `PPIO_API_KEY` |
| 阿里云 | 头像 → AccessKey 管理（建议用 RAM 子账号） | `ALIBABA_CLOUD_ACCESS_KEY_ID` / `_SECRET` |
| 腾讯云 | 访问管理 → API 密钥管理（建议用子账号） | `TENCENTCLOUD_SECRET_ID` / `_KEY` |

阿里云和腾讯云建议**只给 ECS/CVM + VPC 的权限**，别用主账号的钥匙。

## 两件最常做的事

**开一台最便宜的**

点「一键最便宜（扫所有平台）」，回答两句（显存至少多少 G、至少几张卡），
它扫遍所有填了钥匙的平台、按门槛挑最便宜且**有货**的那台，其余十几栏从
上次的配方里来，只剩一个确认框。第一次要把表单填全，之后就记住了
（**密码不存**，每次现填）。

**把模型弄进去**

模型四五十 GB，公网 100 Mbps 下要一个多小时，而抢占式随时会被回收。两条路：

- **自定义镜像**（「自定义镜像…」按钮）：起一台机 → 下好模型 → 关机 →
  存成镜像 → 复制到常用的几个地域。之后新机从镜像开，**零下载**。
- **开机自动拉**（建机表单里那三栏）：模型放 OSS / COS，开机走**内网**拉，
  不计流量费，50 GB 三五分钟。换模型不用重做镜像。

两条可以并用：引擎和常驻模型烤镜像，常换的那几个走对象存储。

开机拉模型走的是 **RAM / CAM 角色**，不是把你的密钥塞进机器——建机前点
「看开机脚本」能看见到底要在你机器上跑什么。

## 几个会当场踩到的地方

- **交换机（子网）的可用区必须和规格的可用区一致**，下拉里都标着可用区。
- **系统盘不能小于镜像**：烤了模型的镜像两三百 GB，默认 100 GB 装不下。
- **带宽填 0 就没有公网 IP**，SSH 连不上，开机脚本也装不了下载工具。
  按流量计费下带宽只是峰值上限、本身不花钱，所以默认拉满 100。
- **抢占式会被回收**（提前几分钟通知），而且**关机之后再开机不保证开得起来**。
  适合「跑完就释放」，不适合当常驻机。

## 自检

```
./changji-cloud --version
./changji-cloud --selftest
```

`--selftest` 不开窗口，把四家的表单都搭一遍再退出——包坏没坏一句话就知道。
